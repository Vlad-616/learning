### Цели
- Реализовать продвинутый CI/CD: окружения, артефакты, стратегии деплоя.

### Задания
1. Сборка → тесты → сборка образа → публикация → деплой в dev, промоут в staging/prod.
2. Включите кэширование/артефакты (пример: кэш npm/go модулей, артефакты junit/reports).
3. Матрица (по версиям языка/SDK) — опционально, если применимо.
4. Стратегия деплоя: blue/green или canary в Minikube (на базе двух Deployment/Service или флагов селекторов).
5. Уведомления: GitHub PR статус, опционально Slack/Email.

### Критерии приёмки
- Прослеживаемость образа (sha) до деплоя, контролируемый промоут.
- Логи и артефакты доступны, кэш ускоряет сборку.
