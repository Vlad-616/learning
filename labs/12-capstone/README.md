### Цели
- Собрать единый выпускной проект, объединяющий все практики.

### Задания
1. Сформируйте продвинутый CI/CD: сборка→тесты→образ→деплой dev→staging→prod.
2. Включите observability: метрики+логи+SLI/SLO+алерты.
3. Обеспечьте безопасность: image scan, SAST/secret scan, политики, секреты.
4. GitOps: деплой через Argo CD; IaC: Terraform/Helm.
5. Нагрузочное тестирование, оптимизация ресурсов/стоимости, отчёт до/после.

### Критерии приёмки
- Репозиторий-резюме: документация, дашборды, пайплайны, IaC, схемы.
- Демонстрация деплоя, наблюдаемости и отказоустойчивости.
