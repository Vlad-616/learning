### Цели
- Описывать инфраструктуру кодом (IaC), безопасно работать со стейтом и модулями.

### Задания
1. Установите Terraform. Создайте модуль для одного ресурса (k8s namespace/secret или облачный ресурс).
2. Настройте backend (локально для обучения или удалённый) и `providers`.
3. Добавьте переменные, outputs и пример `terraform.tfvars`.
4. Включите `terraform fmt`, `validate`, `plan` в CI (без backend, если нужно).
5. Секреты — из переменных окружения/CI secrets, не хранить в гите.

### Критерии приёмки
- `terraform plan` детерминированный, нет неожиданных изменений.
- Конфиг разбит на модули, валидация/формат проходят в CI.

- Ссылка на PR + вывод `terraform plan` и структура модулей.
