### Цели
- Освоить Git-flow, PR, линт/тесты в CI, локальный Jenkins.

### Задания
1. Настройте ветки: `main` защищённая, фичи через PR.
2. Добавьте линтер/форматер (на ваш стек) и простые тесты.
3. GitHub Actions: запуск на PR, статические проверки, junit-репорты.
4. Jenkins локально (docker compose): job сборки и тестов.
5. Сохранение артефактов (reports/) и статуса билда.

### Критерии приёмки
- PR показывает статусы CI, прикреплены отчёты.
- Jenkins job зелёный, артефакты архивируются.
