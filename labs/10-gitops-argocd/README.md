### Цели
- Организовать GitOps-деплой с Argo CD и автосинком.

### Задания
1. Установите Argo CD (Helm или манифесты), откройте UI.
2. Опишите `AppProject` и `Application`, подключите репозиторий.
3. Включите авто-синк и защиту от дрейфа, настройте health checks.
4. Разделите окружения (dev/staging/prod) по каталогам/веткам.
5. Измените версию образа в Git и проверьте автодеплой.

### Критерии приёмки
- Изменения из Git автоматически применяются, история и статус видны в UI.
- Окружения изолированы, политики выставлены.
