### Цели
- Централизовать сбор логов, настроить поиск, ретеншн и корреляцию.

### Задания
1. Установите Loki+Promtail+Grafana или EFK-стек.
2. Переведите приложение на структурированные JSON-логи и добавьте request/trace id.
3. Настройте парсинг и метки в системе логирования.
4. Создайте дашборды и оповещения по лог-событиям (ошибки, таймауты).
5. Настройте ретеншн и политики хранения.

### Критерии приёмки
- Все контейнеры приложения логируются, поиск удобен, парсинг корректный.
- Есть корреляция логов с запросами/трейсами.
